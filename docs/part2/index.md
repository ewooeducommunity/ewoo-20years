# Part 2. 나와 공동체

이우교육공동체 구성원 23인이 자신의 시선으로 기록한 개인 에세이 모음입니다. 학교 설립을 함께 준비하던 이야기, 학부모·교사·활동가로 지내며 겪은 기쁨과 갈등, 그리고 공동체가 자신의 삶에 남긴 흔적을 각자의 문체로 풀어냈습니다. 원문의 표기(필명, 기수, 별명 등)를 가능한 한 그대로 살렸으며, 저자 실명은 각 글의 메타데이터에 표기했습니다.
