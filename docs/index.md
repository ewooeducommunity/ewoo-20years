# 이우교육공동체 20년사

이우교육공동체가 20주년을 맞아 펴낸 기록집을 웹에서 읽을 수 있도록 옮겼습니다.
{ .lead }

발간사부터 정관까지 20년사 전권이 이 사이트에 담겨 있습니다. 본문 곳곳의 인물과 사건은 서로 링크로 이어져 있어, 글을 읽다 낯선 이름이나 사건을 만나면 [역대 임원진](part3/index.md)이나 [연대표](part4/index.md)에서 바로 확인할 수 있습니다.

## 읽는 법

- 처음부터 순서대로 읽고 싶다면 **[발간사](발간사.md)** 부터 시작하세요.
- 특정 인물이나 시기가 궁금하다면 **[역대 임원진](part3/index.md)** 이나 **[연대표](part4/index.md)** 를 먼저 펼쳐 보세요.
